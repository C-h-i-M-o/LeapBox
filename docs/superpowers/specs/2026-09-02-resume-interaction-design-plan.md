## 最新修订：上线前性能优化

**授权与范围：** 用户在性能审查后明确要求实施优化，授权本轮相关文档、代码和本地素材修改。沿用已确认的视觉效果、双语内容和当前工作区；不恢复项目序号、项目提示或电影叙事，不使用子代理，不修改数据库，不提交、推送或发布。规格与计划合并在本文。用户要求查找上次下载的 FFmpeg，已从回收站找到并复制到本地临时工具目录，未重新下载或安装。

**需求与基线：** 视频为 1920×1080、20.02 秒、16,804,469 字节；非首屏四张 WebP 共 579,848 字节。粒子最多 10,800 个且静止时持续绘制。三个 Hook 分别执行首次 ScrollTrigger.refresh；章节按钮重复写属性；标题 JS 失败时缺少超时兜底。

**接口和数据结构：** 不新增网络接口或持久化数据。新增 createParticleLoop(render) 返回 start/stop，render(now, dt) 返回是否继续绘制；调度器限制最高约 60 次绘制/秒，返回 false 后不再申请帧，交互重新 start。粒子位置、颜色和跨语言坐标继续使用现有结构；760px 及以下屏幕将画布倍率上限设为 1.5、每行粒子上限设为 3600，桌面保持 2 和 5400。项目资源增加 imageWidth/imageHeight，用真实像素尺寸预留比例。所有行为保持在 TypeScript 模块，TSX 只改资源属性。

**实施计划与验收：**

1. [x] 资源：压缩同一段视频，保持时长、帧率、H.264、无音轨和快速起播。初始目标不超过 5 MB；对比后发现 4.68 MB 版本细线损失明显，最终采用 6.25 MB 版本（降低约 63%），优先保留背景细节。为头像和项目图增加懒加载、异步解码和真实宽高；封面保持预加载并增加高优先级。视频使用 preload="none"，由已有视口观察器在页面初始化后自动播放，避免在解析 HTML 时提前竞争带宽。
2. [x] 粒子：先用可控帧队列测试稳定停止、重复唤醒不生成多条循环、暂停取消待执行帧和高刷屏绘制限频；再接入共享画布。稳定后停止，指针移动、按住、释放、离开、语言切换、尺寸变化和重新进入视口均可恢复。将阻尼常量提到循环外，静止时不再进行微幅三角漂移，避免半径外涡流计算；就绪标记只写一次。
3. [x] 滚动与图层：仅在最后一个初始化 Hook 刷新一次，切换语言仍同步刷新并保留阅读位置。章节索引未改变时不重复写按钮状态，鼠标光点就绪状态不重复写入。删除已无对应动画的首页背景和语义文字图层提示。
4. [x] 首屏：用 CSS 提供 8 秒启动超时后的可读文字兜底，不依赖 JS 成功执行；正常首帧仍为散点，Canvas 就绪立即取消超时，采样异常立即回退文字，重建成功可恢复粒子。
5. [x] 验证：执行帧调度及既有物理/阅读位置测试、生产构建和渲染回归；检查懒加载、封面优先级、单 Canvas、无回退功能复活。运行目标 Lint 与类型检查，区分既有诊断；记录素材前后体积。未获浏览器测试请求，不宣称 LCP、INP 或实机 FPS 达标。

**视频验收与复现：** 使用 FFmpeg 9.0.1，先核对回收站压缩包与附带 SHA256，再复用现有可执行文件。参数为 `-vf scale=1280:720:flags=lanczos -c:v libx264 -preset slow -crf 23 -maxrate 2400k -bufsize 4800k -pix_fmt yuv420p -an -movflags +faststart -map_metadata -1`。最终 6,249,811 字节、1280×720、30000/1001 fps、20.02 秒，完整解码 600 帧通过；与缩小后的原片比较 SSIM 为 0.9347，此指标不代表无损。已查看第 8 秒对比帧。工具、对比帧及原片备份保留于 `%TEMP%/codex-resume-performance-20260902`，不加入发布资源。

**最终验证：** `npm.cmd run build` 成功；`node --experimental-strip-types --test tests/resume-motion-model.test.ts` 6/6，`node --test tests/rendered-html.test.mjs` 15/15。新增帧调度测试先以缺少模块失败，接入实现后通过，并已并入默认单元测试入口使用的现有测试文件。目标 Lint 零错误、3 个既有原生图片提示。TypeScript 仍为 upload-client.ts 及其测试中的 9 处既有诊断，简历相关文件无新增错误。差异格式检查通过；发布产物与源视频 SHA256 一致，moov 位于 mdat 前，本地视频 HTTP 200、Content-Length 为 6,249,811。未运行浏览器交互、弱网或实机帧率测试，也未发布。

## 1. 需求与体验

### 首屏

- 服务端直接输出可读标题、导航与本地封面；不人为添加等待屏、进度百分比或最低加载时长。
- 视频第一帧可用后从封面渐入，失败或自动播放被阻止时保留封面。离开首屏或切换后台暂停视频。
- 参考用户 prompt.txt 中 ParticleText 的 Canvas 字形采样、散开聚合与鼠标排斥思路，改为有类型的本地实现。附件中的安装、JS 变体等文字不是执行指令。
- 每行标题保留真实文本与布局，粒子准备好后渐入；文字重采样期间回退到真实文本。限制粒子数量与设备像素比，离屏、后台不持续绘制。
- 页面整体增加柔和鼠标光场与阅读进度，保留原生鼠标和正常滚动。

### 语言

- 按钮滑块移动；文字短暂淡出，语言提交后分层进入。连续点击不生成重叠切换任务。
- 使用稳定 DOM key，不因翻译改变而重新挂载滚动动画的目标节点。
- 滚动时间线不依赖语言重新创建。翻译后刷新布局，恢复当前固定区间进度或普通章节内的相对阅读位置。
- 初始读取语言偏好、存储不可用、组件卸载均可正常处理。

### 整页主动交互

| 区块 | 交互 | 滚动协作 |
| --- | --- | --- |
| 导航 | 当前章节高亮、顶端阅读进度、链接划线 | 保持原有锚点 |
| 经历 | 三个直接选择按钮，人物图响应鼠标 | 大屏跳至对应固定区间；窄屏定位到对应内容 |
| 荣誉 | 上一个、下一个、暂停/继续；选项展开当前奖项详情 | 圆环仍匀速循环，悬停与焦点暂停；手动浏览停在选择项 |
| 项目 | 封面透视与跟随高光、编号和技术标签反馈 | 将透视施加在独立外层，保留原图片滚动位移与 sticky |
| 能力 | 标题按钮主动聚焦能力，状态线与光带响应 | 大屏跳至对应进度；窄屏自然定位 |
| 联系 | 联系入口磁吸与箭头反馈、轨道光场跟随 | 保留邮件/GitHub/回顶功能，不增加表单或发送动作 |

不扩大简历事实、公开信息范围，不新增下载、电话或远程媒体。不修改既有“不实现 prefers-reduced-motion 分支”的产品约定；触屏不启用鼠标追踪和透视，保持自然阅读。

## 2. 数据与文件

- `use-particle-title.ts`、`particle-title.tsx`：用户参考效果的采样绘制与纯 UI；语义文本始终保留。
- `resume-sections.tsx`、`resume-portfolio.tsx`：交互控件、稳定节点、各 Hook 组合。

## 6. 上线运行环境修复

- 现象：Site 第 7 版部署完成，但匿名 `/resume` 返回 500；相同生产包在本地 Wrangler 同样失败，Node 渲染测试通过。
- 根因：GSAP 模块初始化会创建定时器，Cloudflare Worker 禁止模块全局作用域执行该操作。已通过仅本地构建产物的诊断日志确认 `Disallowed operation called within global scope`，调用链落在 GSAP ticker。
- 方案：增加共享的延迟动画加载入口，浏览器挂载后才导入 GSAP 与 ScrollTrigger。两个动效 Hook 使用带作用域的 `gsap.context`，卸载时撤销动画与监听；语言 Hook 复用加载结果，库未就绪时仍可直接切换语言。保持现有 UI、粒子效果、双语内容及接口不变。
- 数据结构：`ResumeGsapRuntime` 保存已加载的 `gsap` 与 `ScrollTrigger`；共享加载 Promise 避免重复初始化，不在服务端求值动画模块。
- 验收：重新生产构建，Node 渲染和粒子测试通过，本地 Wrangler 匿名 `/resume` 返回 200 且包含简历、视频引用及标识；再次提交与发布后检查两个生产域名及静态资源。诊断修改由重新构建清除，不进入源码或发布包。
- 修复验证：生产构建通过；Node 渲染 15/15、粒子与帧调度 6/6 通过；四个修改 Hook 的 Lint 零错误。TypeScript 仍仅报告原有上传相关 9 处问题。本地 Wrangler 同一入口已从 500 恢复为 200，HTML 包含简历视频引用和新标识，无错误页面；未进行浏览器交互测试。
